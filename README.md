# 📧 Spam Email Detection

## 📌 Project Description
This project uses Machine Learning to classify SMS messages as **Spam** or **Ham (Not Spam)**. It processes text messages, trains a classification model, and predicts whether a new message is spam.

## 🚀 Features
- Load SMS dataset
- Data preprocessing
- Convert text into numerical features
- Train a Machine Learning model
- Predict whether a message is Spam or Ham

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## 📂 Dataset
- sms.tsv

## 🤖 Machine Learning
- Text Classification
- Feature Extraction
- Spam Detection

## ▶️ How to Run
1. Install the required libraries:
   ```bash
   pip install pandas numpy scikit-learn
   ```

2. Run the project:
   ```bash
   python spam_email_detection.py
   ```

## 📈 Output
The program predicts whether an SMS message is:
- 📩 Spam
- ✅ Ham (Not Spam)
